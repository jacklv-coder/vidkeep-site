收藏链接后如何观看？

在抖音、B站等 App 点“分享”并复制链接，回到 VidKeep 首页点“粘贴”；也可以通过系统分享面板选择 VidKeep。公开作品可尝试下载到本机，完成后离线观看。各来源的支持范围与清晰度见 App 内“链接来源支持”。请仅下载自己拥有或获准保存的内容。需要登录、验证或受限的作品暂不支持。也可以导入本地视频。订阅解除每天的下载次数限制，不会解锁来源限制。

如何下载抖音合集、补集和重试？

粘贴支持的抖音公开合集分享链接，或通过系统分享面板保存后，在 App 内进入选集。保持 App 在前台获取完整目录，再选择单集、集号范围或全选；未确认选集时不会下载任何一集。下载按原集号归入合集，已有本地下载会复用。“下载 → 合集下载”可查看任务、只选未下载的集数、检查合集更新、重试失败和取消未完成任务。重启 App 后选集和任务状态保留；解析阶段仍需前台，具体传输限制取决于来源。此功能不代表支持所有平台的合集、登录后内容或受限作品。

如何设置私密收藏密码？忘记后怎么办？

在“我的 → 私密收藏”设置并确认独立的 6 位数字密码，也可从视频菜单选择“设为私密”。之后可在私密页主动开启 Face ID / Touch ID 快捷解锁。手机锁屏密码不能代替私密密码；关闭私密区或 App 进入后台后自动上锁。忘记密码只能在确认删除本机私密内容后重新设置，不能用新密码找回旧私密内容。私密收藏提供 App 内访问隔离，不是独立文件加密。普通备份不包含私密内容；以前导出的副本和系统设备备份需自行管理。

儿童模式的家长验证与私密密码一样吗？

不一样。锁定模式的退出验证使用系统设备验证（生物识别或手机密码），不可用时使用算术问题；它不能解锁私密收藏。儿童模式只播放家长选好的内容，可设置每日观看时长，没有推荐流。

如何恢复购买或取消订阅？

在“我的”打开 VidKeep Pro，点击“恢复购买”，使用原购买 Apple 账户。管理或取消订阅请使用 App Store 订阅设置。到期不会删除已有内容。

每天免费下载 5 个如何计算？

收藏链接、导入本地文件和恢复备份都不限数量。从链接开始下载视频时计 1 次，按本机日期每天重置。合集中的每个视频分别计次，读取目录和勾选本身不扣次数，复用已有下载也不会再扣一次。同一条链接重试不重复计数，下载失败或取消会退回这次额度；删除已下载的视频不退回。当天用完后，新链接照常收藏，第二天打开 VidKeep 会自动继续下载。

如何备份？

在“我的 → 备份与恢复”导出普通收藏备份，或开启自动备份，保存到你选择的文件夹（例如 iCloud 云盘）。备份包含普通视频、分类、合集、进度和笔记，排除私密内容与合集下载状态，公开单集链接可保留为普通书签。可保留普通合集来源信息；恢复后需重新获取目录、选择要下载的集数，不能依靠备份恢复原设备的未完成队列。文件未加密。系统设备备份按系统设置处理，卸载前请分别确认普通和私密内容的保留方式。

导入本地文件时可以离开页面吗？

文件导入时可以返回收藏页继续浏览。关闭应用前请等待导入完成；若导入被系统中断，请在导入任务中重试。下载来源视频时，获取视频需要保持 App 打开；能否在后台继续传输取决于来源，详见 App 内“链接来源支持”。手动强制退出可能中断任务，重开后可重试。

Help in English

Copy a video link from TikTok, YouTube or another supported app, then tap Paste on VidKeep Home. You can also choose VidKeep in the system share sheet. Public videos can be downloaded to this device when available; YouTube is saved up to 1080p, and live streams, members-only and age-restricted videos are not supported. Only download content you own or have permission to save. Works requiring login or verification are not supported. Keep VidKeep open while finding the video. YouTube downloads require VidKeep to remain open; see Supported Sources in the app for other background transfer limits. You can also import your own or licensed local videos for offline playback and timestamped notes. Restore purchases from the Pro screen.

For supported public Douyin collections, keep the app open to load the complete directory, then choose episodes or ranges. Collection Downloads offers missing-episode selection, updates, failure retry and cancellation. Saved videos follow source episode order; existing downloads are reused. Selections and task progress persist after restart. Each video uses a separate daily download allowance; reading the directory does not. Other platforms’ playlists and restricted works are not included.

Me > Private Collection lets you set a separate 6-digit PIN and optionally enable Face ID/Touch ID. The device passcode does not replace this PIN. Closing the private area or backgrounding the app locks it. A forgotten PIN can only be reset after confirming deletion of local private content. The separate Kids mode parent gate uses system device authentication, or an arithmetic check when unavailable; it cannot unlock private items.

Export an ordinary-collection backup or enable automatic folder backup before uninstalling. These unencrypted backups exclude private content and unfinished collection queues, but can keep ordinary collection source information for fresh lookup and selection after restore. System device backups follow system settings. Private Collection provides in-app access protection, not independent file encryption or protection for copies outside the app.

Use the button above to open a public GitHub issue. Include reproduction steps and app/iOS versions only. Never include private videos, sensitive URLs, personal contact information or account credentials.
